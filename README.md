# 🎰 Python Slot Machine

A beginner-friendly Python slot machine game with randomized symbols, betting, weighted probabilities, and different payouts.

## 🎮 Features

- 🎰 25 different slot machine symbols
- 🔢 Numbers from 0 to 9
- 🍒 Fruits and classic symbols
- 🎲 Randomized spins
- ⚖️ Weighted symbol probabilities
- 💰 Betting system
- 🏆 Different payouts
- 💥 Jackpot for 7️⃣ 7️⃣ 7️⃣
- 🔄 Play again option
- ❌ Input validation
- 💸 Balance tracking

## 🎯 How It Works

The player starts with a balance of `$100`.

Before each spin, the player chooses a bet.

The machine generates three random symbols. Matching symbols result in winnings:

- 3 matching symbols → higher payout
- 2 matching symbols → `2×` the bet
- No matching symbols → the bet is lost
- `7️⃣ 7️⃣ 7️⃣` → jackpot
